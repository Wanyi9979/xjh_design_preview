# 海心个案 AI 助手（Pad 框架）

这是面向个案管理人员的 Pad 端 AI 助手框架页面，参考了个案管理 AI 页面，并使用 `@ant-design/x` 的 `Conversations`、`Welcome`、`Prompts`、`Sender`、`Bubble` 组件组织交互。

页面采用海心设计基础规范的「云个案」色彩模式和 Pad 字体层级：保留个案工作台左侧导航，并将助手作为全局 CARES 吉祥物入口。助手支持小面板、大面板，以及“左侧对话 + 右侧业务详情”的分栏状态。

## 本地运行

建议使用 Node.js 24。默认访问端口为 5187，若被占用，开发服务会选择可用端口。

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
```

三类简报和患者范围测试：`pnpm test`。

## 当前范围

- 当前患者、会话和回答不连接患者系统、医学知识库或 AI 服务。
- 常用管案任务包含三类简报、通俗解释和沟通策略。输入框工具栏提供医学知识、简报和产品功能解答；产品功能解答提供本地操作说明，不读取患者资料。
- 通俗解释和沟通策略入口仅填入可编辑的文字提示词，不显示任务标签，也不会自动发送；切换这两个入口会替换提示词并保留已输入内容。
- 欢迎页的“常用管案任务”标题与五个入口保持固定，选择任务只更新输入框。医学知识和产品功能解答的示例问题放在独立的“你可以这样问”区域，点击后填入草稿，确认后再发送。
- 回答反馈提供“有帮助 / 需改进”两种评价。需改进支持多选快捷原因和可选补充说明，可不填写直接提交；提交后收起面板并保留点踩状态。点击已选图标可撤销反馈。
- 悬浮入口贴在页面右边缘：吉祥物可沿右侧上下拖动，轻点或点击后助手面板从同一侧连续展开。鼠标悬停时，身体保持稳定，手臂做一次自然挥手并配合一次眨眼；触摸设备直接点按打开。小面板输入框支持医学知识和简报任务标签，标签可删除且不会清空草稿。
- 简报类型为：呼叫前简报、入院简报、患者情况总结简报。入院简报保留任务标签并填入含“【入院时间：明日】”的提示词，可将明日改成具体日期（如 `2026-10-20` 或 `10月20日`），发送时校验并使用所填日期。患者范围只在需要生成简报时选择，不作为输入框上方的全局状态。
- 定时任务默认提供呼叫前简报、入院简报两条配置，可以按这两种类型新建多条任务，编辑名称、患者范围、执行时间和频率。入院日期默认相对执行日为明日，也可选当天、后天、自定义天数或指定日期；指定日期按一次性任务配置。删除任务保留已有简报和运行记录，在“已删除”列表查看。当前仍为会话内交互演示，未接入后台自动执行服务，刷新后恢复默认数据。
- AI 回答中的业务链接会展开右侧患者详情、入院准备或随访记录，并保留左侧工作台导航和助手对话。
- 正式接入时，替换 `src/assistantData.ts` 中的当前数据和 `buildDemoReply`，并保留授权范围、来源回溯、审计和人工复核入口。

## 吉祥物素材

当前入口使用侧身探出的完整素材 `public/cares-mascot-peek-full.png`，保持原先的倾斜探头、左手挥手和右手扶边姿态，并补齐自然的衣摆、裤腿和鞋子。整体向右隐藏 30px，仅露出一只脚，不使用渐隐。`public/cares-mascot-peek-repair.png` 由内置 AI 图像生成服务补出手臂后的身体和闭眼状态。两张图对齐在同一画布，SVG 分层裁切只替换手臂后方与眼镜内的眼睛，CSS 关键帧控制挥手和眨眼。素材与生成提示词见 [docs/mascot-assets.md](docs/mascot-assets.md)。旧版素材保留为备份。

在开启系统“减少动态效果”的浏览器里，可用 `?motion=on` 临时查看完整动效；默认页面仍遵循系统动效偏好。

安装 Pillow 后运行 `python3 scripts/build-mascot-assets.py` 可重新制作素材。
