# 临研配置中心访视管理与访视计划模板配置需求说明

## 1. 产品概述

本说明覆盖项目详情中的访视管理列表，以及从版本行进入的访视计划模板配置二级页面。

### 1.1 产品目标

- 在项目详情内查看访视版本列表
- 为指定版本和访视周期配置访视计划模板

### 1.2 需求范围

- 访视管理版本列表
- 访视计划模板配置二级页面
- 计划模板创建、编辑、保存草稿、发布与确认
- 访视计划配置弹窗

## 2. 功能结构

| 模块 | 需求说明 |
| --- | --- |
| 访视管理列表 | 展示访视版本及版本级操作入口。 |
| 访视计划模板配置 | 围绕版本与访视周期管理计划模板、模板卡片和模板编辑。 |
| 访视计划规则配置弹窗 | 配置访视计划规则中的 CRF、计划详情、采集、填写、自动映射和完成时限。 |

## 3. 详细功能需求

### 3.1 访视管理列表

展示访视版本及版本级操作入口。

#### FR-001 列表改造

1、操作新增：访视计划模板配置。点击按钮进入对应版本的计划模板配置二级页面。

2、新增计划模板列，回显当前模板配置情况。

### 3.2 访视计划模板配置

围绕版本与访视周期管理计划模板、模板卡片和模板编辑。

#### FR-002 顶部面包屑

1、页面顶部显示“返回”和版本配置标题，点击【返回】回到版本列表页面。

2、左侧为“访视周期”树与“搜索访视”，右侧展示当前访视周期的计划模板区域。

#### FR-003 访视周期树与模板数量标识

1、切换周期，右侧展示对应的模板列表。

2、若该周期已有模板，会在周期行显示“模板 N”。草稿+发布的都算

#### FR-004 空状态与创建模板

1、当前访视周期没有模板时显示空状态。

2、点击【创建计划模板】进入模板编辑态，模板标题默认取当前访视周期名称。

#### FR-005 模板卡片列表与操作

1、已有模板以卡片展示，包含模板名称、计划项数量、最近修改时间、发布时间和状态。

2、卡片支持复制；草稿状态支持删除；已发布状态支持启用或停用。均需二次确认。

（1）停用：已发布状态的模板支持停用，停用后全病程不能再使用该模板

（2）删除/修改：草稿状态的模板支持删除/修改  
（3）复制：复制成功后自动生成新的模板名称：原模板名称+下划线+递增号。模板状态为草稿状态。

#### FR-006 创建/编辑计划模板

1、点击【返回】回到模板列表

2、名称自动填入当前周期名称，在一个周期下，名称不可重复

#### FR-007 保存草稿与发布校验

1、点击【取消】直接回到创建页面。

2、点击【保存草稿】：

（1）校验模板名称的必填以及重复，不做计划的相关校验。

（2）保存成功后，页面自动返回创建页面，并在最上方新增一条为草稿状态的计划模板。

3、点击【发布】：

（1）需进行名称的必填和重复性校验，以及计划的必填校验。

（2）校验通过后需二次确认。确认后，相关模板下发至对应治疗组。

（3）发布成功后，页面自动返回创建页面，并在最上方新增一条为发布状态的计划模板。

#### FR-008 模板操作二次确认

复制、删除、发布和停用等模板操作共用确认弹窗。弹窗包含标题、说明文案、“取消”和“确认”按钮；发布确认文案为“发布后下发至对应治疗组”。

### 3.3 访视计划规则配置弹窗

配置访视计划规则中的 CRF、计划详情、采集、填写、自动映射和完成时限。

#### FR-009 关联 CRF与计划内容

1、关联 CRF 按当前访视的 CRF 表单渲染。

2、计划内容手动填写，这个内容作为计划内容回显到外面的计划条

#### FR-010 采集方式

1、采集方式默认选中【文件】

2、切换为表单时，下方显示【选择问卷】配置项，问卷选择项--对应项目问卷库回显即可。

#### FR-011 填写方式

1、个案填写：仅个案账号。

2、仅患者填写：患者/个案均可，患者端显示对应计划任务。

### 3.补充 已确认需求

#### FR-012 计划模板

1、默认创建一条类型为访视计划的计划。

2、计划不可全部删除，至少保留一条。

3、计划类型包括：访视计划、提醒计划、患教计划，切换时，对应的配置项不同。默认绑定当前访视，禁用只读。

4、提醒和患教配置项与原全病程一致，不做赘述。

#### FR-013 自动映射

1、默认选择【是】，上传对应文件/填写问卷后自动ai识别映射至对应访视周期。

2、选择【否】，不自动映射

#### FR-014 计划完成时限

1、支持设置计划完成时限，计划在规定时限内完成不视为逾期，超过时限未完成则标记为逾期。

2、计划完成时限配置  
（1）支持根据当前访视窗口期结束日期与计划日期自动计算可完成天数，自动填入，可修改。  
（2）完成时限天数=当前访视窗口期结束日期-计划日期。  
3、默认打开，关闭后，下方输入框禁用。视为无逾期范围，超过计划日期即逾期。

#### FR-015 确认

1、必填未填写时，按钮禁用。填写后恢复可用。

2、确认后在计划列表上回显：计划详情

## 4. 全局交互与业务规则

- 模板配置入口按版本进入并显示对应版本标题
- 模板操作涉及发布、复制、删除、停用时使用二次确认
- 必填或重复校验不通过时以 toast 和红色状态提示

## 5. 验收标准

- [ ] 访视管理列表显示版本号、版本日期、版本说明、计划模板和操作列
- [ ] 点击访视计划模板配置后显示对应版本的配置计划模板二级页面
- [ ] 选择不同访视周期后右侧模板列表与左侧模板数量标识同步更新
- [ ] 发布模板前完成必填校验和重复标题校验
- [ ] 配置访视计划弹窗中必填项满足前确认按钮保持禁用

## 6. 待确认事项

- 原型未确认模板数据的后端保存接口、权限控制和异常处理规则
- 原型未确认真实日期、版本号、发布状态与治疗组下发的数据来源
