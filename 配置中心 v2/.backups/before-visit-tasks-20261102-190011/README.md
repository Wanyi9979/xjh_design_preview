# AI-EDC · 临研配置中心

根据下载目录中的“临研-配置中心 4”建立的独立项目，保留原始页面、图片素材和设计说明。

## 本地启动

在此项目目录打开终端并执行：

```bash
python3 -m http.server 4174 --bind 127.0.0.1
```

浏览器访问 http://127.0.0.1:4174/ 。如已安装 npm，也可执行 `npm start` 或 `npm run dev`。无需安装依赖或构建。

## 文件说明

- `index.html`：默认入口，原版配置中心交互页面。
- `index-带设计说明.html`：带设计标注的页面。
- `index-带设计说明-分享版.html`：设计说明分享版。
- `assets/`：原始图片素材。
- `.design-notes/`：需求说明、标注数据和标注脚本。

## 功能范围

包括临床试验列表与详情、中心及账号映射、访视管理、访视计划模板和数据采集配置等原型交互。具体业务规则见 `.design-notes/DESIGN-NOTES.md`。

当前为静态交互原型，数据来自原页面的演示数据，未连接后端服务；不应将页面上的保存或发布提示视为真实业务数据已提交。原页面保留 Figma 捕获辅助脚本，加载该脚本需要网络。

## CRF 数据来源配置

入口：临床试验 → 查看详情 → 访视管理 → 版本行「数据来源配置」。顶部复用访视管理，左侧按 CRF 汇总使用访视并支持已配置/未配置筛选，右侧关联、移除项目问卷。切换 CRF 保留草稿，点击保存草稿或发布后写入本浏览器 localStorage，按项目与版本隔离。

直达预览：http://127.0.0.1:4174/?page=data-sources&version=V2.0

新增 `data-sources.css` 与 `data-sources.js`；原页面备份在 `.backups/before-data-sources-20261021/index.html`。带设计说明的历史 HTML 保持原样。

原型数据说明：CRF 及使用访视来自原页面 `visitCrfData`，该原始演示数据未按版本区分，各版本暂共用它，但映射配置独立保存。演示 OID 由明确字典指定；正式接入需使用同步接口的 CRF ID、结构版本及项目/版本下的访视引用。项目问卷范围由显式项目清单模拟，目前仅 SYX-ML46252 配有问卷，其他项目为空；V2.0 的生命体征、人口学资料含初始演示关联。未连接真实问卷接口或 AI 服务，不执行真实预填。
