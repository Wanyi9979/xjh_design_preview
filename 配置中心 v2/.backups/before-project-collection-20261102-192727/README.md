# AI-EDC · 临研配置中心

根据下载目录中的“临研-配置中心 4”建立的独立项目，保留原始页面、图片素材和设计说明。

## 本地启动

在此项目目录打开终端并执行：

```bash
python3 -m http.server 4174 --bind 127.0.0.1
```

浏览器访问 http://127.0.0.1:4174/ 。如已安装 npm，也可执行 `npm start` 或 `npm run dev`。无需安装依赖或构建。

## 文件说明

- `index.html`：默认入口，原版配置中心交互页面。
- `index-带设计说明.html`：带设计标注的页面。
- `index-带设计说明-分享版.html`：设计说明分享版。
- `assets/`：原始图片素材。
- `.design-notes/`：需求说明、标注数据和标注脚本。

## 功能范围

包括临床试验列表与详情、中心及账号映射、访视管理、访视计划模板和数据采集配置等原型交互。具体业务规则见 `.design-notes/DESIGN-NOTES.md`。

当前为静态交互原型，数据来自原页面的演示数据，未连接后端服务；不应将页面上的保存或发布提示视为真实业务数据已提交。原页面保留 Figma 捕获辅助脚本，加载该脚本需要网络。

入口：临床试验 → 查看详情 → 访视管理 → 版本行「数据来源配置」。顶部复用访视管理，左侧按 CRF 汇总使用访视并支持已配置/未配置筛选，右侧关联、移除项目问卷。切换 CRF 保留草稿，点击保存草稿或发布后写入本浏览器 localStorage，按项目与版本隔离。

直达预览：http://127.0.0.1:4174/?page=data-sources&version=V2.0

### 草稿与发布

保存草稿只保存编辑副本，不覆盖已发布映射；发布会更新已发布映射并清除草稿。再次进入优先恢复已保存草稿。旧版保存的数据兼容迁移为已发布基线。当前仍为本地原型，发布不调用真实服务。


## 访视任务（2026-11）

入口：访视管理 → 版本行「访视任务配置」。直达：http://127.0.0.1:4174/?page=visit-tasks&version=V2.0

采用左侧「访视任务 / 问卷管理 / 映射配置」导航，去掉原整行版本返回栏；版本号位于左侧「版本功能」旁。点击顶部「访视管理」可返回版本列表。

- 支持搜索、分组／执行方式／状态筛选、分页、新建、查看、编辑、删除未发布草稿。
- 支持全部组或指定分组，按访视、每日／每周周期采集、按需填写三类规则。访视任务以计划访视日为锚点；周期任务在填写日 00:00 开放，当天指定时间截止。
- 任务按项目与访视版本保存在浏览器 localStorage。任务保存草稿与发布分别保存；编辑已发布任务不会直接覆盖已发布快照，支持撤销草稿。
- 问卷管理可从当前项目演示库关联固定内容版本；已被草稿、已发布任务或 CRF 映射引用的问卷不能移除。映射配置沿用原模块。
- 新模块文件为 `visit-tasks.js` 和 `visit-tasks.css`。未更改带设计说明的历史 HTML。

演示范围：仅 SYX-ML46252 / V2.0 预置五个任务；其他版本任务初始为空。试验组、对照组及问卷内容版本为演示数据，项目问卷库仍为本地显式清单；访视沿用原型同步数据，暂未接入分组、问卷及版本接口。发布仅保存本地配置，不生成真实患者任务、不触发消息、不处理患者版本迁移或 AI 预填。旧计划模板代码保留但已替换其版本列表入口。
